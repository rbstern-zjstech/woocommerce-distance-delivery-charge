# WooCommerce Distance-Based Delivery Charge

This WooCommerce plugin adds a configurable delivery fee based on the shipping address distance from a fixed origin point.

## Features
- Calculates delivery charge using Google Maps or straight-line distance
- Allows you to set base location and fee per mile/km
- Fully compatible with WooCommerce shipping zones and checkout

## Installation
1. Upload the plugin folder to `/wp-content/plugins/`
2. Activate the plugin through the WordPress admin
3. Set origin and rate options under **WooCommerce → Settings → Shipping**

## Usage
This plugin hooks into WooCommerce's shipping calculator and adds a custom delivery fee based on distance from your specified origin coordinates.
